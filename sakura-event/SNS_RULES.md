# SNS_RULES — SNS投稿の生成ルール

## 1. 基本

- SNS投稿は **確認済みの event.json だけ** から生成します（チラシの生データや外部情報は使いません）。
- 媒体3つ × 種類3つ ＝ **最大9投稿**。
- Phase 1 はテンプレートと抜粋による生成（外部AIなし）です。将来 AI adapter を使う場合も、下記のルールと禁止表現チェックを同じように通します。
- 生成結果は「下書き」です。投稿前に担当者が読み、必要に応じて修正します。

| 種類 | 内容 | 必要な情報（なければ生成しない） |
|---|---|---|
| A. 公演のお知らせ | 何が・いつ・どこで・いくら・どうやって申し込むか | タイトル、日付 |
| B. アーティストの魅力 | 出演者紹介。プロフィールからの抜粋 | 出演者の `profile`（1人以上） |
| C. プログラム内容について | 曲目・内容の紹介 | `program.items`（1件以上）。複合イベントは `sub_events`、WSは内容説明 |

### 情報不足時の表示（AIで補完しない）

| 条件 | 表示 |
|---|---|
| B でプロフィールが1件もない | **出演者プロフィール情報を追加してください** |
| C でプログラムが登録されていない | **プログラム情報が登録されていません** |
| A でタイトルまたは日付がない | **タイトルと開催日を確認してください** |

## 2. 媒体ごとの構成（同じ文章の文字数違いにしない）

### 全媒体共通：「公演のお知らせ」（A）に必ず入れるもの

- **出演者**（「出演：名前（楽器）」。4名以上は3名＋「ほか」。講座・ワークショップは「講師：」）
- **発売日時**：`tickets.sales_schedule` の販売方法ごとに、チラシの販売方法の文言・発売日・発売時刻をそのまま（例「さくらプラザ先行電話予約：8月15日（土） 14:00〜」）。販売・受付状況が「未設定」「発売前」のときに載せる
- 販売・受付状況は**チラシから仮定しない**（「発売中」などは担当者が設定した場合だけ使う）

### X（即時性・簡潔）

- 1行目：状態があれば【完売】【受付中】など＋タイトル
- 2行目：日時（`7/4(土)14:00開演`）と会場を1行で
- 3行目：魅力を1点だけ（A：料金や対象年齢／B：出演者と楽器／C：代表的な曲1〜2曲）
- 最終行：URL（詳細ページへの導線）
- ハッシュタグは最大2つ
- 文字数：X の重み付き文字数（全角2・半角1・URLは23）で **280以内**。超える場合は年齢→料金→発売日時の順に削る。タイトル・出演者・日時・URLは削らない

### Facebook（背景・詳しく）

- 冒頭：イベントの紹介（チラシの紹介文 `description` があればそのまま引用、なければタイトルと種別から事実のみ）
- 本文：
  - A：日時・会場・料金・発売日・チケット取扱・対象年齢を見出し記号つきで列挙
  - B：出演者ごとに名前・役割/楽器・プロフィール抜粋（2〜3文）
  - C：曲目を作曲者ごとに列挙、プログラムの注記
- 末尾：詳細ページURL、問い合わせ先
- ハッシュタグは付けないか最大2つ

### Instagram（フック・改行・リズム）

- 1行目：短いフック。**チラシにある `catchphrase` を優先**。なければ「◯月◯日（◯）、さくらプラザで」のような事実だけの一文
- 2行ごとに空行を入れ、1行は短く（おおむね全角20字前後）
- 絵文字は情報の見出し記号としてのみ使用（📅日時 📍会場 🎫料金 など）。装飾的な連続絵文字は使わない
- URLは本文に貼っても押せないため「詳しくはプロフィールのリンクから」と記載し、URL自体は末尾に参考として記載
- ハッシュタグ：末尾に空行を置いてまとめる。5〜10個
  - 固定：`#さくらプラザ` `#戸塚区民文化センター` `#戸塚`
  - event.json にある情報からのみ：出演者名（空白除去）、楽器（`#ピアノ`）、ジャンル、種別（`#ワークショップ` `#0歳からのコンサート` は年齢表記がある場合のみ）
  - 作曲者名（C）

## 3. 禁止・注意表現

入力資料（event.json 内の原文）に同じ語がない限り、次の表現を生成しません。生成物に含まれていた場合は警告を表示します（`js/core/phrases.js`）。

| 区分 | 例 |
|---|---|
| 最上級・誇張 | 必見、絶対に見逃せない、世界最高、最高峰、史上最高、奇跡の、伝説の、唯一無二、No.1、日本一、世界一 |
| 煽り | 急げ、今すぐ、ラストチャンス、お見逃しなく、売り切れ必至、残りわずか（※ status が few_tickets の場合を除く） |
| 根拠のない評価 | 圧巻の、感動必至、話題の、大人気、超絶技巧、至高の |
| 根拠のない経歴 | 受賞、〜コンクール優勝、〜で絶賛（プロフィール原文にない場合） |

- 「残りわずか」「完売」などの販売状況は、`status.code` から機械的に出す場合のみ使います。
- 形容を足したいときは、担当者が確認済み event.json の `catchphrase` や `description` に書き加えてください（出典は `manual` になります）。

## 4. 共通の表記

- 日付：`7月4日（土）`（X は `7/4(土)`）。曜日は日付から計算した値を使います（チラシ表記と一致していることは確認ゲートで保証）。
- 時刻：`14:00開演（13:30開場）`
- 料金：`一般 3,000円／学生 1,500円`。無料は「入場無料」または「参加無料」
- 会場：`戸塚区民文化センター さくらプラザ` ＋室名（venue の値）
- 状態が `sold_out` `registration_closed` `cancelled` `postponed` `finished` の場合、A の先頭に状態を明記し、購入・申込を促す文を出しません。
- 更新履歴に出演者変更がある場合、A と B に「出演者が変更になりました（日付）」を入れます。

## 5. 画像代替テキスト（alt）

- メイン画像（チラシ表面）：`「{タイトル}」のチラシ表面。{日付}、{会場}。詳細は本文に記載。`
- 出演者写真：`{名前}（{楽器/役割}）の写真`。写真の見た目（服装・表情など）は自動で書きません（人が確認して追記）。
- SNS用：Instagram 画像の代替テキスト（最大 100字程度）も同じ規則で生成します。
