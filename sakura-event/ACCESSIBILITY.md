# ACCESSIBILITY — WCAG 2.2「AAA対応チェック」方針

## 基本姿勢

- 生成するHP用HTML、およびこのアプリ自体の画面は、**WCAG 2.2 Level AAA の成功基準を可能な限り満たす** ように作ります。
- ただし適合はページ全体（CMSのテンプレート、ヘッダー、ナビゲーション、実際の画像の内容など）で決まるため、**システムだけで「AAA適合」と断定しません。** 画面・報告書での表現は常に **「AAA対応チェック」** とします。
- チェック結果は **「自動検査」** と **「人による確認が必要な項目」** に分けて表示します。

## 1. 生成HTMLの実装方針

| 観点 | 実装 | 関連SC |
|---|---|---|
| セマンティックHTML | `header` `main` `nav` `section` `article` `footer`、見出し、リスト、`dl` を用途どおりに使う | 1.3.1 |
| 見出し階層 | ページ全体：`h1`＝イベント名、各セクション `h2`、下位 `h3`。飛ばさない。CMS貼り付け用断片は `h2` 始まり（設定で変更可） | 1.3.1, 2.4.6, 2.4.10 |
| ランドマーク | 完全ページ：`header` / `nav`（ページ内目次） / `main` / `footer`。各 `section` は `aria-labelledby` で見出しと結びつける | 1.3.1, 2.4.1 |
| lang属性 | `<html lang="ja">` | 3.1.1 |
| 一部の言語 | 出演者のローマ字名・欧文曲名に `lang="en"`（`roman_name`、ラテン文字のみの値を自動判定。判定は人が確認） | 3.1.2 |
| 読み（発音） | 出演者名に読みがあれば `<ruby>` で表示 | 3.1.6 |
| 代替テキスト | すべての `img` に `alt`。チラシ画像は内容を要約したaltと、本文に同じ情報があることを明記 | 1.1.1 |
| figure / figcaption | メイン画像・出演者写真は `figure` と `figcaption`（キャプション・クレジット） | 1.1.1, 1.3.1 |
| time要素 | 日付・時刻は `<time datetime="2026-07-04T14:00+09:00">` | 1.3.1 |
| リスト構造 | 出演者・曲目・料金・チケット取扱・更新履歴は `ul` / `ol` / `dl` | 1.3.1 |
| 表の不使用 | レイアウト目的の `table` は使わない。料金も `dl` で表現 | 1.3.1 |
| 色だけに頼らない | 状態は記号＋文字（例「✕ 完売」）。リンクは下線 | 1.4.1 |
| コントラスト | 本文・リンク・フォーカス枠とも背景に対して 7:1 以上（CSS変数で定義し、テストで計算） | 1.4.6, 1.4.11 |
| キーボード操作 | 独自のウィジェットを使わず、標準の `a` / `button` / `details` のみ | 2.1.1, 2.1.3 |
| フォーカスの可視化 | `:focus-visible` に 3px 以上の実線アウトライン＋オフセット（コントラスト 7:1 以上） | 2.4.7, 2.4.13 |
| フォーカスが隠れない | 固定ヘッダーを使わない。`scroll-margin-top` を指定 | 2.4.11, 2.4.12 |
| スキップリンク | 完全ページの先頭に「本文へ移動」 | 2.4.1 |
| リンクテキスト | 「こちら」「詳細」だけのリンクを作らない。例「チラシ（PDF、表面、1ページ）を開く」。外部サイトは「（外部サイト）」と明記 | 2.4.4, 2.4.9 |
| ターゲットサイズ | リンク・ボタンは 44×44 CSS px 以上（`min-height` と `padding`） | 2.5.5, 2.5.8 |
| 略語 | `Pコード` `Lコード` `WS` などは `<abbr title>` と用語説明 | 3.1.4 |
| 見慣れない語 | 「膝上鑑賞」「未就学児」「当日券」「開場」等、チラシで使われた語はページ末尾の「ことばの説明」で説明し、本文から `dfn` / リンク | 3.1.3 |
| 読みやすさ | 1文を短く、箇条書き中心。長い紹介文は人による確認項目 | 3.1.5 |
| 状況の変化 | 完売・中止・変更は冒頭の状態表示と更新履歴に文字で記載 | 3.2.5 |
| 電話番号 | `<a href="tel:">` とし、読み上げやすい表記（ハイフン区切り）を維持 | 2.4.4 |

## 2. このアプリ（入力画面）の方針

| 観点 | 実装 |
|---|---|
| フォームラベル | すべての入力欄に `label`。補足説明は `aria-describedby` |
| エラーの特定 | エラーは文字で表示（例「エラー：曜日が一致しません（チラシ：金／日付から計算：土）」）。欄に `aria-invalid="true"` |
| エラー修正の提案 | 「2026年7月4日は土曜日です。日付か曜日のどちらかを修正してください」のように修正案を併記 |
| ステータスメッセージ | 解析完了・コピー完了・確認数の変化は `role="status"`（`aria-live="polite"`）で通知 |
| ステップ表示 | `nav` 内の `ol`、現在のステップに `aria-current="step"` と「（現在）」の文字 |
| 確認状態 | ✓確認済み／！要確認／－情報なし を記号＋文字＋色で表示 |
| 読み上げ順序 | DOM順＝見た目の順（左：チラシ、右：情報）。CSSで順序を入れ替えない |
| 誤操作の防止 | 確定・データ消去は確認ダイアログ。確定後も event.json を再編集可能（3.3.6） |
| ヘルプ | 各STEPに「この画面ですること」を表示（3.3.5） |
| タイムアウトなし | 時間制限を設けない（2.2.3） |

## 3. AAA対応チェック（js/a11y/check.js）

生成したHTMLを DOM として解析し、次の2区分で報告します。

### 3.1 自動検査（プログラムで判定）

| ID | 内容 | SC |
|---|---|---|
| A01 | `html` に `lang="ja"`（完全ページ） | 3.1.1 |
| A02 | ラテン文字だけの名前・曲名に `lang` 属性 | 3.1.2 |
| A03 | `h1` が1つ（完全ページ） | 1.3.1 |
| A04 | 見出しレベルの飛び越しがない | 1.3.1 |
| A05 | 空の見出しがない | 2.4.6 |
| A06 | `main` ランドマークがある（完全ページ） | 1.3.1 |
| A07 | スキップリンクがあり、移動先の id が存在する | 2.4.1 |
| A08 | すべての `img` に `alt` がある。altがファイル名や「画像」だけではない | 1.1.1 |
| A09 | `figure` に `figcaption` がある | 1.3.1 |
| A10 | `time` の `datetime` が有効な日付・時刻 | 1.3.1 |
| A11 | リンクテキストが空・「こちら」「詳細」「click」だけではない。URLそのものだけではない | 2.4.4, 2.4.9 |
| A12 | 同じリンクテキストで行き先が違うリンクがない | 2.4.9 |
| A13 | レイアウト用 `table` がない（`table` があれば `caption` と `th` 必須） | 1.3.1 |
| A14 | id が重複していない | 4.1.1相当 |
| A15 | 状態表示に文字がある（色だけでない） | 1.4.1 |
| A16 | CSS変数の文字色と背景色のコントラストが 7:1 以上 | 1.4.6 |
| A17 | リンク・ボタンの最小サイズ指定が 44px 以上 | 2.5.5 |
| A18 | `:focus-visible` のスタイルがある（3px以上） | 2.4.7, 2.4.13 |
| A19 | 略語（Pコード等）に `abbr[title]` | 3.1.4 |
| A20 | 見慣れない語に「ことばの説明」がある | 3.1.3 |
| A21 | 「情報なし」「要確認」がページに残っていない（確定版） | ― |
| A22 | 禁止表現（必見・世界最高 等）が根拠なく含まれていない | ― |
| A23 | 外部リンクに「外部サイト」の明示 | 3.2.5 |

### 3.2 人による確認が必要な項目

| ID | 内容 | SC |
|---|---|---|
| M01 | 代替テキストが画像の内容・目的を正しく伝えているか | 1.1.1 |
| M02 | 見出しの文言がセクション内容を表しているか | 2.4.6 |
| M03 | 読み上げ順序が意味の順序として自然か（CMSに貼り付けた後） | 1.3.2 |
| M04 | CMSのヘッダー・メニューを含めたキーボード操作、フォーカスが隠れないこと | 2.1.3, 2.4.12 |
| M05 | CMSのテンプレートの配色・文字サイズでもコントラストが保たれるか | 1.4.6 |
| M06 | 紹介文・プロフィールが中学生程度で理解できる読みやすさか（難しければ補足） | 3.1.5 |
| M07 | 自動判定した欧文（lang="en"）が本当に英語か（独・仏・伊語なら lang を修正） | 3.1.2 |
| M08 | チラシPDF自体のアクセシビリティ（タグ付きPDFか）。HP本文に同じ情報があること | 1.1.1 |
| M09 | 動画があれば字幕・音声解説・手話の有無 | 1.2.x |
| M10 | 画像内の文字（チラシ画像）の情報が本文にすべて書かれているか | 1.4.9 |
| M11 | 用語説明が適切か、追加すべき語がないか | 3.1.3 |
| M12 | 点滅・自動再生するコンテンツがないか | 2.3.2, 2.2.2 |

報告書は、自動検査の「合格／不合格／該当なし」と、人による確認項目のチェックリスト（未確認）を並べて出力します。**自動検査がすべて合格でも「AAA適合」とは表示しません。**
