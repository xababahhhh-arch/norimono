# のりもの あてっこ Ver.4

2〜3歳向けの「のりもの名前あてゲーム」です。文字が読めなくても、絵・声・タップで遊べます。

## ファイルの中身
| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み |
| style.css | 色・大きさ・動き |
| app.js | ゲームのしくみ（問題・声・紙吹雪） |
| vehicles.js | **乗り物の一覧（名前・読み方・絵）** ← 画像差し替えはここ |
| nakama-data.js | **なかまわけ の問題と絵** ← 問題を足すのはここ |
| nakamawake.js | なかまわけ ゲームのしくみ |
| tools/check-data.js | 問題データの確認用（ゲームでは使いません） |
| sw.js | オフラインで遊ぶための仕組み |
| manifest.webmanifest / icons/ | ホーム画面に追加したときのアプリ名とアイコン |
| images/ | 差し替え用の画像を入れる場所 |
| sounds/ | 本物の乗り物の音を入れる場所 |

## Ver.4：知育ゲーム「なかまわけ」を追加
- はじめに「🚄 のりもの」「🧠 なかまわけ」を選ぶ ホーム画面を追加（のりものゲームは そのまま）
- なかまわけ：「どうぶつは どれ？」などの問題に、大きな絵をタップして答える（1回5問）
  - 2たく／3たく を選べる。こえ あり／なし を選べる（こえ の設定は のりものゲームと共通）
  - まちがえても「もういちど やってみよう」で やりなおし。時間制限・点数・ゲームオーバーなし
  - 正解したら「つぎへ」で進む。5問おわると スタンプが5つ
  - 動きを減らす設定の端末では アニメーションしない

### なかまわけ の問題を増やす・直す
1. `nakama-data.js` の `NAKAMA_QUESTIONS` に問題を足す（書き方はファイルの先頭に説明があります）
2. 絵が足りなければ `NAKAMA_ITEMS` に足す（のりものの絵は `vehicle: 'id'` で そのまま使えます）
3. パソコンで `node tools/check-data.js` を実行し、「OK」と出ることを確認する
   （正解が2つになる問題や、書きまちがいを自動で見つけます）
4. `sw.js` の `norimono-v6` の数字を1つ上げる

## Ver.3 で増えたこと
- 乗り物を50種類追加（全部で62種類）。ずかんは「しんかんせん」「でんしゃ」などの見出しつき
- 設定の「出てくる乗り物」で、なかまごとに まとめて オン・オフできる
- **声と音の録音**（設定 → 🎙 声と音の録音）
  - 「なまえ」と「ことば（は、どれ？／せいかい！など）」を録音すると、iPhoneの読み上げの代わりに おうちの人の声で問題を出す
  - 「おと」に駅や道で録った本物の音を入れると、正解したとき・ずかんで流れる
  - 録音は その端末の中だけに保存（インターネットには送られません）
- 作りものの乗り物の音はやめました（本物の音だけを流します）
- 「〜車」を「くるま」と読みまちがえる言葉は、ひらがなで読ませるように修正

## 本物の音をファイルで入れる
1. `sounds` フォルダに音声ファイル（mp3 / m4a）を入れる（例: `sounds/kyukyusha.mp3`）
2. `vehicles.js` のその乗り物の `sound: ''` を `sound: 'sounds/kyukyusha.mp3'` にする
3. `sw.js` の `norimono-v3` の数字を1つ上げる

## Ver.2 で増えたこと
- 正解すると、乗り物が走っていく
- 「ずかん」モード：さわると名前を言う（クイズの前に覚える用）
- むずかしさ：かんたん（2つから選ぶ）／ふつう／むずかしい（似た仲間どうし）
- 出てくる乗り物を選べる
- 10秒さわらないと、もう一度やさしく問題を読む
- 読み上げを自然な日本語に（「消防車は、どれ？」のように、漢字・句読点入りで読ませる）
- 声の種類を選べる（片言に聞こえる「おもしろ声」は自動で使わない）

## もっと自然な声にするには（iPhone）
1. 「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」
2. 「Kyoko」や「O-ren」の **拡張** または **プレミアム** をダウンロード
3. ゲームの設定（歯車を長押し）→「声の種類」でその声を選ぶ

## 保護者向けの操作
- はじめの画面の右下の小さな歯車を **長押し（約1秒）** → 設定（問題の数、むずかしさ、出てくる乗り物、声の種類、話す速さ、効果音）
- ゲーム中に左上の家マークを **長押し** → はじめの画面にもどる

## 画像を差し替える
1. `images` フォルダに画像を入れる（例: `images/hayabusa.png`、横長がおすすめ）
2. `vehicles.js` の該当の乗り物の `image: ''` を `image: 'images/hayabusa.png'` に変える
3. `sw.js` 1行目付近の `norimono-v1` を `norimono-v2` に変える（iPhoneに新しい版を確実に届けるため）
